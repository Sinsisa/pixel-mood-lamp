# Mood Lamp Control Board

Manufacturing exports for the separate custom ESP32 control board designed for the Pixel Mood Lamp.

- [Gerber and drill ZIP](Mood_Lamp_Control_Board_Gerber.zip)
- [Bill of materials](Mood_Lamp_Control_Board_BOM_JLCPCB.csv)
- [Component placement / CPL](Mood_Lamp_Control_Board_CPL_JLCPCB.csv)

These are the Iteration 1 manufacturing exports from the original project archive. The control board has not been manufactured or hardware-tested. The working lamp shown in the project photos uses an Arduino Uno and a separate supply. Review this design before ordering; publishing the files does not establish electrical or charging performance.

For assembled boards, provide the Gerber ZIP, BOM and CPL together. Confirm component availability, orientation and assembly options with the manufacturer.
